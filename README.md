# Nuestra boda · Sarahí & Alan

Invitación animada inspirada en talavera mexicana. Fecha: 30.08.2027.

## Publicación

Sitio estático, sin instalación ni compilación. GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Actualizaciones

Modificar index.html, style.css, app.js o los archivos en assets/ y subir los cambios a main. GitHub Pages publica la actualización automáticamente cuando está habilitado.

## Música (pendiente)

Formato recomendado: MP3. Se añadirá al recibir la canción, con inicio después de tocar Abrir invitación y control para silenciar.

## Recursos visuales

Las imágenes de assets/ son piezas derivadas de la referencia de la invitación. No se incluye la foto original completa ni credenciales de alojamiento.
